# YouTube 頻道順序播放（Chrome 外掛）

看 YouTube 時，依照**同一頻道的上傳順序**切到下一部（較新）或上一部（較舊）影片，
也可以在影片播完後自動接著播。不需要 API key、不需要登入。

## 安裝（開發者模式載入）

1. 開 Chrome，網址列輸入 `chrome://extensions`
2. 右上角開啟「開發人員模式」
3. 點「載入未封裝項目」，選這個資料夾（含 `manifest.json` 的那層）
4. 打開任一 YouTube 影片，影片下方會出現一條控制列

## 使用

- 影片下方控制列：**◀ 上一部（較舊）** / **下一部（較新） ▶**，中間會顯示這部是頻道第幾部（由新到舊）
- 快捷鍵：`Alt+Shift+→` 較新的下一部、`Alt+Shift+←` 較舊的上一部（Mac 的 Alt = Option；可在 `chrome://extensions/shortcuts` 改）
- 點工具列圖示可以設定：
  - 播完自動接續（開/關）與方向（由舊看到新，或由新看到舊）
  - 跳轉前等待秒數（預設 0，立刻跳轉可以搶在 YouTube 自己的自動播放之前）
  - 是否把 Shorts 與直播算進順序
  - 是否顯示控制列

建議把 YouTube 播放器右下角的「自動播放」開關關掉，避免兩邊搶著跳。
當網址帶有 `list=`（你正在看某個播放清單）時，外掛不會介入自動接續。

## 原理

每個 YouTube 頻道都有一個系統自動維護的「上傳清單」播放列表：
把頻道 ID 的 `UC` 前綴換成 `UU` 就是全部上傳，換成 `UULF` 則只有一般影片（不含 Shorts、直播）。
這個清單嚴格依上傳時間由新到舊排列。

外掛流程：

1. 用 YouTube 的 oEmbed 端點查出目前影片的頻道（精準對應影片 ID，不會被單頁換頁時的舊畫面誤導）
2. 讀頻道頁面取得頻道 ID（`UC...`），結果會快取
3. 讀取 `UULF...` 播放清單頁，找不到目前影片就用 YouTube 內部的 continuation 一頁一頁往後翻（每頁約 100 部，最多 60 頁）
4. 目前影片的前一個 = 較新的下一部，後一個 = 較舊的上一部
5. 影片 `ended` 事件觸發時，依設定方向跳轉

清單快取 15 分鐘，同一頻道連續看不會重複抓。

## 已知限制

- 會員限定、私人、尚未公開的影片不在上傳清單裡，會顯示找不到
- 用 `/watch?v=` 開 Shorts 時，預設會先把 `UULF` 清單翻完才改用 `UU`，大頻道會多等幾秒；常看 Shorts 可以在設定勾「包含 Shorts 與直播」
- 跳轉是整頁重新載入（約 1 秒），不是 YouTube 的站內換頁
- YouTube 改版時，控制列插入的位置（`ytd-watch-flexy #below`）可能要調整；找不到時會退回右下角的浮動面板

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `manifest.json` | 外掛設定（MV3） |
| `content.js` / `content.css` | 注入 YouTube 頁面的主程式與樣式 |
| `background.js` | 把快捷鍵轉成訊息送給頁面 |
| `popup.html` / `popup.js` | 工具列設定面板 |
| `_locales/` | 中文（zh_TW）與英文（en）介面文字，依瀏覽器語言自動切換 |
| `icons/` | 圖示 |
| `dist/` | 上架用的 zip 與宣傳圖 |
| `STORE_LISTING.md` / `PRIVACY_POLICY.md` | Chrome Web Store 上架文案與隱私權政策 |
